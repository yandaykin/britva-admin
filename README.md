# BRITVA — ADMIN / BAZA

Статический сайт GitHub Pages. Откройте `index.html` через локальный HTTP-сервер.

## Обновление прайса

Прайс обновляется вручную из Google Таблицы:
https://docs.google.com/spreadsheets/d/1jzxCqz0yVi16YWqQOuIzB8jAs0_GiTy3Lp66f6M16iI/edit

Листы: «Барбер» (26060901), «Топ-барбер» (26060902), «Бренд-барбер» (26060903).
В A — услуги и категории, в B/C — цены основной градации и подградации. Первые четыре строки — заголовки.

В `index.html` замените объект `PRICE_2026` между маркерами `BEGIN PRICE_2026_DATA` и `END PRICE_2026_DATA`, сохраняя структуру `groups → categories → items`. Укажите дату переноса в `updated`. Встроенный снимок на 09.10.2026 содержит актуальные на момент чтения изменения пользователя.

- Число `0` означает нулевую цену; отсутствие цены — `null`.
- Диапазоны цен сохраняются строками, например `2 000–4 000 ₽`.
- Строки без обеих цен и пустые категории скрываются.
- Общие категории перечислены в `sharedCategories`: уход за лицом, дополнительные услуги, окрашивание и завивка. Недостающие общие услуги добавляются из листа «Барбер» во все группы. Явная запись в выбранной группе имеет приоритет.
- Названия и категории берутся из листов без сокращения. Удалённые из источника позиции не восстанавливаются из старого прайса.
- Длительность в прайсе не отображается.
- «Угадай цену» использует тот же `PRICE_2026`, что и прайс. Перед началом выбирается одна из шести градаций; общие услуги, абонементы, диапазоны и нулевые цены сохраняются, отсутствующие цены исключаются. Варианты ответа берутся из реальных цен выбранной градации.
- «Зачёт прайса» использует `PRICE_2026`: выберите градацию, затем категорию. Нужно вписать цены только выбранной градации. Для диапазона вводятся обе границы через дефис или тире; пробелы не влияют на проверку. Пустой ответ отличается от нуля. Сохранён прежний порог сдачи: количество ошибок не больше `ceil(количество позиций × 0.2)`.
- «Угадай услугу» использует `PRICE_2026` и выбор одной из шести градаций. Вопросы включают общие услуги, абонементы и диапазоны; отсутствующие цены исключаются. Услуги с той же ценой или пересекающимся диапазоном не попадают в неверные варианты ответа, поэтому среди четырёх вариантов один правильный. Сохранены 15 вопросов и прежний подсчёт результатов.
- Данные калькулятора и режима «Сравнение» (`window.BRITVA`) независимы от нового прайса; изменение их состава требует отдельного обновления.

После правки проверьте все три вкладки, клавиатуру, мобильную ширину 320–390 px и цены в исходной таблице. Дополнительные проверки: `node tests/price.test.cjs`, `node tests/trainer.test.cjs` и `node tests/exam.test.cjs` (внешние пакеты не нужны).
