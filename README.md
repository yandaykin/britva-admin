# BRITVA — ADMIN / BAZA

Статический сайт GitHub Pages. Откройте `index.html` через локальный HTTP-сервер.

## Обновление прайса

Прайс обновляется вручную из Google Таблицы:
https://docs.google.com/spreadsheets/d/1jzxCqz0yVi16YWqQOuIzB8jAs0_GiTy3Lp66f6M16iI/edit

Листы: «Барбер» (26060901), «Топ-барбер» (26060902), «Бренд-барбер» (26060903).
В A — услуги и категории, в B/C — цены основной градации и подградации. Первые четыре строки — заголовки.

В `index.html` замените объект `PRICE_2026` между маркерами `BEGIN PRICE_2026_DATA` и `END PRICE_2026_DATA`, сохраняя структуру `groups → categories → items`. Укажите дату переноса в `updated`. Встроенный снимок на 09.10.2026 содержит актуальные на момент чтения изменения пользователя.

- Число `0` означает нулевую цену; отсутствие цены — `null`.
- Диапазоны цен сохраняются строками, например `2 000–4 000 ₽`.
- Строки без обеих цен и пустые категории скрываются.
- Общие категории перечислены в `sharedCategories`: уход за лицом, дополнительные услуги, окрашивание и завивка. Недостающие общие услуги добавляются из листа «Барбер» во все группы. Явная запись в выбранной группе имеет приоритет.
- Названия и категории берутся из листов без сокращения. Удалённые из источника позиции не восстанавливаются из старого прайса.
- Длительность в прайсе не отображается.
- Данные калькулятора и тренажёра (`window.BRITVA`) независимы от нового прайса; изменение их состава требует отдельного обновления.

После правки проверьте все три вкладки, клавиатуру, мобильную ширину 320–390 px и цены в исходной таблице. Дополнительная проверка: `node tests/price.test.cjs` (внешние пакеты не нужны).
